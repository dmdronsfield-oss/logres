# Brief 7: phone-ready

The game is meant for a phone in the hand. Smooth the edges a phone player meets first.

## 1. A real loading screen
About 2 MB of knights load over mobile data. Show the title in the loading screen with a gold progress
bar and what's loading ("Arming Sir Gawain…"), instead of a word on a dark screen.

## 2. Don't rely on colour alone
Red (unparryable) and gold (parryable) can look alike to colour-blind players. Unparryable blows get a
**dashed** ring and a small ✕ by the glint, as well as the red, so shape alone tells them apart.

## 3. Graphics setting
The game already steps its quality down if frames drop. Add a **Graphics: High / Medium / Low** choice
to the pause menu, so a player can choose battery life or looks. It's remembered.

## Done when
Loading shows progress; the dashed ring reads in a screenshot; the setting changes quality live; the bot
still passes; release published.
